Getting started

CT Cardiac Calcium Score pilot

Prepared for Dr. Luis Ramos

There is nothing to install and no admin rights needed. RadAssist runs right in your web browser, and no patient data ever leaves your computer — the tool makes zero network calls once the page has loaded.

Open it

1

Click the tool link

Open it in Chrome or Edge. That is it, you can use it immediately.

2

Keep it handy (optional)

Bookmark it (Ctrl+D), or install it as an app for a desktop icon: in Chrome, ⋮ menu → Cast, save, and share → Create shortcut… → check Open as window. In Edge: ⋯ → Apps → Install this site as an app. It will then live in your Start menu like any program.

3

Verify it works

Enter Left Main 0, LAD 14, LCx 2, RCA 9, Age 65, Male, Hispanic and click Generate. You should see total 25 and percentile ~51. If you do, you are all set.

Open RadAssist →
Prefer fully offline? With the tool open, press Ctrl+S and save the page to your computer. The saved copy runs with no internet at all. Either way, nothing you type is ever transmitted.

Privacy

Everything runs on your machine. No patient identifiers are needed or stored — only the scores plus age, sex, and ethnicity. Nothing is saved after you close it. To "uninstall," just remove the bookmark or app shortcut.
